          Instalar o Antigravity

          É gratuito, com um limite de uso que renova toda semana.

          1. Baixe a versão do seu sistema em antigravity.google/download. Só baixe desse endereço.
          2. Instale como qualquer programa e abra.
          3. Entre com a conta Google que você conferiu.
          4. No painel Settings (o programa é em inglês), decida se o Google pode usar suas conversas para melhorar os produtos. Na conta pessoal, isso vem ligado; dá para desligar.
          5. Abra uma pasta de teste, não uma pasta com seus arquivos de verdade.

          Para casa: o opencode

          O mesmo jeito de trabalhar, pelo terminal, com modelos gratuitos. Precisa do Node.js, que o guia ensina a instalar. Depois:

          npm install -g opencode-ai

          No Windows, o próprio opencode recomenda usar o WSL. Guia completo em opencode.ai/docs.

          Deu erro? Pergunte ao monitor

          Enquanto a IA não estiver instalada, o monitor ajuda. Depois, cole a mensagem de erro inteira na própria IA e pergunte o que fazer.

            Ele propõe, você aprova

            Quando precisa fazer algo fora do comum, o agente pergunta antes. Leia o que ele pede.

            O agente quer executar um comando

            pip install pdfplumber

            Para ler as tabelas dos PDFs, preciso de uma biblioteca que ainda não está instalada.

            O pip é o instalador de bibliotecas do Python. No programa, estes botões aparecem em inglês.

            Quanto ele faz sem perguntar

            1. Request Review(pedir revisão) pergunta antes de qualquer comando
            2. Default(padrão) pergunta antes do que é sensível. É o que usamos no curso.
            3. Auto(automático) decide sozinho o que pode executar
            4. Turboroda qualquer comando, sem pedir confirmação. Não use.

            No Antigravity: Settings › General › Global Permissions › Permission Preset. O Auto ainda está em teste (Preview).

            Você guarda o original, a IA trabalha na cópia

            Não conte com um botão de desfazer no Antigravity. A proteção é a cópia que você mesmo faz, pelo Explorador de Arquivos.

            1. meus-dadosos originais, só seusDeixe os arquivos de verdade numa pasta.
            2. meus-dados - Cópiaonde a IA vai trabalharCopie a pasta inteira (Ctrl+C, Ctrl+V) e dê um nome claro.
            3. meus-dados - Cópiaaberta no agenteNo agente, abra só a cópia. A pasta original fica fora do alcance dele.
            4. meus-dados - Cópia (2)antes de um passo grandeAntes de um passo grande, copie de novo. Deu errado? Volte para essa cópia.

            No opencode existe o comando /undo, que desfaz a última mudança. A cópia vale para os dois.
