How to read these numbers

  • Where the scores come from — the three categories use composite indices from Artificial Analysis, which runs its own tests under the same protocol for every model rather than republishing vendor claims. The how this category is measured button shows each index’s composition and test weights, with a link to the full methodology.
  • The three categories are not independent — Overall capability is the full Intelligence Index; Coding and Agents and automation are two isolated components of it (24% and 34% of the score). Together they make up 58% of the overall score. This is why the three lists rank models similarly; the main difference is the distance between models. Correlation figures appear under how we measure for each tab.
  • What “overall capability” means — the model’s ceiling on difficult tasks (professional work, tool use, coding and doctoral-level science), not its quality for conversation, writing or summarization; none of the nine tests measures those skills. For everyday tasks, almost any model on these lists is sufficient.
  • Sort — most capable uses the category score; value for money uses the highest score per dollar rather than the lowest price; fastest uses tokens per second. Each row’s bar shows the active criterion.
  • Quality floor — because the list already contains the most capable models, value and speed compare only models above a minimum capability level.
  • Compare — search for a model or select the + button in a row to place up to four models side by side. The table shows each model’s score and rank in every category; “—” means the model was not evaluated in that test.
  • Clickable names — open the model on the timeline. We link only exact name matches; models that are not yet registered appear without a link.
  • Price and speed — average cost per million tokens (combined input and output, in USD) and generation speed. “—” means the source does not publish the figure.
  • Missing categories — there is no mathematics category because available tests are saturated (leaders score above 99%, with no separation among current models). The research and reasoning and instructions and data categories were removed in August 2026 when Artificial Analysis moved individual tests to its paid plan, leaving only composite indices. Research remains in the calculation: the scientific reasoning block represents 24% of Overall capability. The source also does not evaluate front-end, so the coding score does not assess interface development.
